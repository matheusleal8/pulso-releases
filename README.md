# Pulso — instaladores

Automações de WhatsApp e Instagram que rodam no seu computador.

## Instalar
1. Abra **Releases** (à direita) e baixe o `PulsoSetup-<versão>.exe` mais recente.
2. Dê dois cliques. Se o Windows mostrar "O Windows protegeu o computador", clique em **Mais informações → Executar assim mesmo**.
3. No Pulso: **Configurações → Abrir janela de login** e escaneie o QR do WhatsApp; depois **Instagram → Abrir Instagram**.

## Atualizar
O Pulso avisa quando há versão nova (**Atualizar para vX** no topo ou em Configurações → Atualizações). Logins, mensagens e automações são preservados.

Cada instalador é publicado com o SHA-256 nas notas da versão; o Pulso confere esse valor antes de instalar.
